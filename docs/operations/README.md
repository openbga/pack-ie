# Operator guides

Use these guides on the computer running Positive ACK. The console and CLI connect
locally to the same engine; closing the console leaves the engine running.

| Guide | What it covers |
| --- | --- |
| [Install](install.md) | Install the package, connect the console, manage the service, upgrade and uninstall. |
| [First channel](first-channel.md) | Configure a serial bridge or an ASTM-to-HL7 message channel, with complete runtime documents. |
| [Running and monitoring](running-and-monitoring.md) | Read states, messages, logs and alerts, and operate channels from the console or CLI. |
| [Troubleshooting](troubleshooting.md) | Find the cause of a failure, recover safely and prepare support information without patient data. |
| [Configuration reference](configuration-reference.md) | Look up fields, defaults and limits for bootstrap and runtime configuration. |
| [Laboratory compliance](compliance.md) | Assign safeguards, validate interfaces, inventory PHI and prepare retention, incident and downtime procedures. |
| [Compliance sources](compliance-sources.md) | Date, status and verification of each source the compliance guide cites. |

Start with Install, then First channel. The [behavior specifications](../spec/) give the
full rules behind these guides.
